String Sinth: a guitar string synthesizer based on a mathematical formulation.

During this project it was developed a application to synthesize a guitar audio signal through recursive equations. So drawing on the techniques and mathematical models available in the literature, a solution was implemented using Python.

When a tensioned string is disturbed by a wave, the elements that compose it move perpendicularly to the direction of propagation. This relationship can be described by a partial differential equation, where y represents the displacement at time t and position x along the string, i.e., y(x, t). Mathematically, this behavior is expressed by the following equation, where v is the wave propagation velocity.

\[ \frac{\partial^2 y}{\partial x^2} - \frac{1}{v^2} \frac{\partial^2 y}{\partial t^2} = 0 \]

However, this equation neglects losses inherent to real oscillations, as well as the effects of the string material on the phenomenon. To account for these non-ideal characteristics, an expanded wave equation is proposed at An interdisciplinary study of the timbre of the classical guitar, as shown in the equation bellow. In this formulation, the first two terms are identical to those in previous equation. The parameter γ represents a damping factor and models energy dissipation effects, such as air friction, energy transfer from the string to the instrument body, and internal damping within the string. The term l is a dimensionless parameter related to the string stiffness and is proportional to the Young's modulus and to the string radius, and also inversely proportional to its linear density. For simplicity, the parameter l is used directly.

\[ l = \frac{E \pi r^4}{\mu} \]

\[ \frac{\partial^2 y}{\partial x^2} - \frac{1}{v^2} \frac{\partial^2 y}{\partial t^2} - \gamma \frac{\partial y}{\partial t} - l^4 \frac{\partial^4 y}{\partial x^4} = 0 \]

The presented formulation, however, is expressed in terms of continuous derivatives and therefore cannot be directly implemented on a computer, which operates on discrete values. A common approach is to apply numerical approximations for derivatives. For instance:

\[ \frac{\partial u}{\partial x} = \frac{u_{i+1}^j - u_{i-1}^j}{2\Delta x} \]

\[ \frac{\partial^2 u}{\partial x^2} = \frac{u_{i+1}^j - 2u_i^j + u_{i-1}^j}{\Delta x^2} \]

Combining this approximations with the proposed formulation, it was possible to implement a string synthesizer based on a mathematical formulation.
